The first Slipstream you can install and use without a terminal: a desktop app, a background service, and catching downloads from your browser.

## What's new since 0.1.0
- **Desktop app**: download list with live speed, ETA and a per-connection segment bar; Add URL; pause, resume, delete, open folder; settings (download folder, connections per file, speed limit, catching on/off). Light: about 25 MB of RAM. On Windows it lives in the tray.
- **"Download caught" popup** when the browser hands a download over.
- **Background service** (`slipstream-daemon`): keeps the list, survives restarts and continues unfinished downloads.
- **Browser catching** for Chrome, Edge, Brave, Vivaldi and Chromium (tested on Windows and Linux): normal clicks on files, the right-click menu, and downloads behind a login (your cookies go along). Firefox support is included but less tested.
- **Smarter speed**: adds connections only while they make it faster, so it no longer slows down on lines one connection already fills.

## Install
- **Windows 10/11**: run `Slipstream-Setup-0.2.0.exe` (no administrator rights needed). It registers itself with your browsers. The installer isn't code-signed yet, so Windows may show "Windows protected your PC": choose *More info* → *Run anyway*.
- **Debian/Ubuntu**: `sudo apt install ./slipstream_0.2.0-1_amd64.deb`, then start *Slipstream* from your app menu.
- **Other Linux / portable**: the `.tar.gz` and `.zip` archives hold the four programs; run `slipstream register-browsers` once.

## Browser extension
The extension isn't in the browser stores yet. Until it is:
- **Chrome / Edge / Brave**: unzip `slipstream-extension-chrome-v0.2.0.zip`, open `chrome://extensions`, turn on Developer mode, click *Load unpacked* and pick the folder.
- **Firefox**: `about:debugging` → *This Firefox* → *Load Temporary Add-on* → the `manifest.json` in the unzipped Firefox package (temporary until a signed version is published).

## Known limits
- Preview release. HTTP(S) downloads only; no video streams, FTP or proxy settings yet.
- Downloads made by a form POST stay in the browser.
- Alt+click to force a catch doesn't work reliably yet; use the right-click menu.
- No tray icon on Linux yet: closing the window ends the app, downloads keep going.

Every file has a `.sha256` next to it.
